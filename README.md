# [Rishinstall]

A dead simple barebones 55-line installer script for shizuku on termux

If shizuku is already installed, ask confirmation before overwriting, if it isnt installed, then it installs to ~/.local/bin/rish.

## installer

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/byscourge/rishinstall/master/rishinstaller.sh)
```

## Usage
```bash
rish
```
